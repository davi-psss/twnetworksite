## 📖 Sobre o Projeto

O site da **TW Network** é a porta de entrada para a nossa comunidade. Desenvolvido para ser rápido, moderno e imersivo, ele funciona como a plataforma central do nosso servidor focado em **RankUP**, com economia 100% personalizada e sistemas de **Minigames** que premiam os melhores jogadores com dinheiro real!

Atualmente, este repositório contém o **Front-end** da plataforma, construído com foco máximo em experiência do usuário (UX) e interface de usuário (UI).

---

## ✨ Funcionalidades (Implementadas e Planejadas)

O site não é apenas uma vitrine, é uma extensão da jogabilidade. Aqui está o que ele oferece e oferecerá:

- 🛒 **Loja Dinâmica:** Compra de VIPs, Cash e itens personalizados com sistema de carrinho de compras e checkout intuitivo.
- 📊 **Painel de Status Real-Time:** Monitoramento de jogadores online, uptime e status dos minigames.
- 🔗 **Sincronização com o Jogo:** Sistema de login sincronizado com a conta do Minecraft para recolher presentes diários/especiais no site e receber in-game.
- 📚 **Wiki / Guia do Jogador:** Uma seção detalhada com os comandos básicos, tutoriais de economia e dicas de RankUP.
- 📬 **Newsletter:** Inscrição para receber novidades, atualizações de temporadas e promoções da loja.
- 📋 **Click to Copy (IP):** Botão interativo para copiar o IP do servidor rapidamente.
- 💬 **Hub de Comunidade:** Acesso rápido às nossas redes sociais e canal oficial de suporte.

## 🚀 Tecnologias Utilizadas

Para garantir um design de tirar o fôlego e uma performance absurda, estamos utilizando e implementando a seguinte stack tecnológica:

### 🛠️ Base
- **[React](https://reactjs.org/)** - Biblioteca JavaScript para criação da interface.
- **[Vite](https://vitejs.dev/)** - Empacotador super rápido para o ambiente de desenvolvimento.

### 🎨 Design & Animações (Sugestões Premium implementadas no projeto)
- **[Tailwind CSS](https://tailwindcss.com/)** - Framework CSS utilitário para criar um design responsivo e moderno com muita facilidade.
- **[Framer Motion](https://www.framer.com/motion/)** - Biblioteca para criar animações fluidas, transições de páginas e efeitos nos botões (trazendo muita vida ao site).
- **[Lucide React](https://lucide.dev/)** - Ícones limpos, bonitos e altamente customizáveis.

### ⚙️ Gerenciamento e Estrutura Futura
- **[Zustand](https://github.com/pmndrs/zustand)** - Para gerenciar o estado global do **Carrinho de Compras** de forma leve e rápida.
- **[Axios](https://axios-http.com/)** - Preparado para a futura integração (Back-end) com a API do servidor para pagamentos e sincronização de recompensas.
